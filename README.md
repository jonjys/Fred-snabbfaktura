# SnabbFaktura

Professionell svensk fakturagenerator – 100 % privat, ingen registrering.

**Live:** https://snabbfaktura.vercel.app

## Funktioner
- Svensk moms (25/12/6/0 %)
- PDF, live preview, historik
- 3 mallar, CSV-export (Pro)
- Stripe Pro: 49 kr/mån eller 490 kr/år

## Pro
Betala via Stripe Payment Links. Efter köp redirectas du tillbaka med `?pro=success` och Pro låses upp lokalt.

Demo-kod: `DEMO`

## Tech
Statisk HTML + Tailwind CDN + jsPDF. Deployad på Vercel.
