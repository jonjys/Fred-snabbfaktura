# SnabbFaktura

Beautiful invoices in 30 seconds. Global · Private · Fast.

**Live:** https://snabbfaktura.vercel.app

## Features
- EN / SV language toggle
- 11 currencies with proper locale formatting
- Tax profiles: SE, NO, DK, DE, UK, US, EU, zero, custom
- Discount (percent or fixed)
- 3 templates (Classic, Minimal, Bold/Pro)
- Invoice history, CSV export (Pro)
- Dark mode
- Stripe Pro: 49 SEK/mo or 490 SEK/yr
- 100% client-side — no data leaves the browser
