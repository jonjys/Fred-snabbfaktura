# SnabbFaktura

Beautiful invoices in 30 seconds. **Global · Private · Fast.**

**Live:** https://snabbfaktura.vercel.app

## What's new (v2 — international upgrade)

- **6 languages:** English, Svenska, Deutsch, Français, Español, Norsk
- **18 currencies** with proper locale formatting
- **18 tax profiles:** SE, NO, DK, DE, FR, UK, ES, IT, NL, AT, FI, PL, US, CA, AU, JP, EU, zero + custom
- **5 templates:** Classic, Minimal, Bold, Elegant, Modern (3 Pro)
- **Logo upload** + **accent color** (Pro)
- **Unit field** on line items
- **Localized dates** per language
- **Invoice history** with Load + Duplicate
- **CSV export** (Pro)
- Dark mode, live A4 preview, sample data per language
- 100% client-side — no data leaves the browser
